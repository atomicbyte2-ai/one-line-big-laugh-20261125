# One Line, Big Laugh

> I told my smart speaker I needed motivation, so it said 'have you tried turning yourself off and on again' — now we're both in therapy.

`main.ts` holds the entry line as a constant, validates it (1–200 characters, a single line with no newline or control characters and no leading or trailing whitespace), and writes it — with no trailing newline — to `entry.txt` in the directory given by `MAKEFUN_OUTPUT_DIR` (default `/output`).
